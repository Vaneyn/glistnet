Что за терминал и для чего он нужен?

Этот терминал поможет вам выполнить несколько команд. Вот пара из них с описанием их функционала:

1. js # (# это ваш ввод) поможет вам выполнить код на javascript, супер. Пример ввода: var b = 20; var sum = a + b; alert("Сумма чисел " + a + " и " + b + " равна " + sum);

2. color # изменит цвет вывода на экран. 3. run # запускает любое приложение из Glist.Вот пара из них: r sleep strobo binary и другие.
